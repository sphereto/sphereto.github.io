## About this site

A single-page, static personal site (`index.html`) with an animated intro. No build step, no dependencies.

To preview locally, open `index.html` in a browser, or run:

```sh
python3 -m http.server 8000
```

## Deployment

Pushing to `main` deploys the site to GitHub Pages via GitHub Actions
(`.github/workflows/deploy.yml`). In the repository, go to
**Settings → Pages → Build and deployment → Source** and choose **GitHub Actions**.
